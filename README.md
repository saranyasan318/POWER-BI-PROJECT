##📊 Sales Performance Dashboard | Power BI Project

📌 Project Overview

This project is an interactive Sales Performance Dashboard built using Power BI.  

The dashboard analyzes sales trends, regional performance, customer segments, product sales, and category-wise distribution to generate meaningful business insights.

The project helps businesses understand:

- Sales performance across regions

- Top-selling products

- Customer segment contribution

- Monthly sales trends

- State-wise sales distribution

---

 🚀 Tools & Technologies Used

- Power BI

- Power Query

- DAX (Data Analysis Expressions)

- Data Visualization

- Excel/CSV Dataset

---

📂 Dataset Features

The dataset contains:

- Order ID

- Order Date

- Sales

- Quantity

- Category

- Segment

- Region

- State

- Product Name

---

 📈 Dashboard Features

🔹 KPI Cards

- Total Sales

- Total Orders

- Total Quantity

- Average Sales

🔹 Visualizations

- Monthly Sales Trend Analysis

- Regional Sales Comparison

- Category-wise Sales Distribution

- Customer Segment Analysis

- Top 10 Products by Sales


🔹 Interactive Filters

- Region Filter

- Category Filter

- Segment Filter

- Order date Filter
